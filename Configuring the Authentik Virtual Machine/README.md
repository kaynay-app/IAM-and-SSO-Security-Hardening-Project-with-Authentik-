# Configuring the Authentik Virtual Machine

The Authentik IAM application is hosted directly on a lightweight Alpine Linux virtual machine provisioned with the following hardware specifications and software initialization sequences.

## 💻 Virtual Machine Specifications
* **Memory:** 2 GB
* **Processors:** 1
* **Hard Disk:** 1
* **CD/DVD Drive:** Alpine Linux OS .iso file
* **Network Adapter 1:** Private Lab Switch (Isolated Sandbox Lab)
* **USB Controller:** Present
* **Video Card:** Auto detect
